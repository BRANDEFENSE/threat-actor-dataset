# Contributing

This dataset is maintained by the Brandefense Research Team. Corrections are welcome.

## Report a data error

1. [Open an issue](https://github.com/BRANDEFENSE/threat-actor-dataset/issues/new?template=data-correction.md).
2. Name the entry (group, malware, technique or CVE) and the field that is wrong or missing.
3. Add a public source (government advisory, MITRE ATT&CK, vendor research). Entries only change when a public source supports the change.

## Pull requests

The files in `data/` and the entry pages are generated from the Brandefense Knowledge Hub, so pull requests that edit them directly are overwritten at the next update. Please open an issue instead; we apply the fix at the source.
