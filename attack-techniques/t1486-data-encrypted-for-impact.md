# Data Encrypted for Impact

Data Encrypted for Impact is when attackers encrypt files or whole systems so the owner can no longer use them, and then hold back the key. It is the core step of ransomware. MITRE ATT&CK lists it as an Impact technique.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1486 |
| Tactic | Impact |
