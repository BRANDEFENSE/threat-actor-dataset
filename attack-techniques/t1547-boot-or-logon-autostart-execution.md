# Boot or Logon Autostart Execution

Boot or logon autostart execution is when an attacker sets up a computer so that their program starts by itself when the system boots or a user logs on. This lets the attacker stay on the system after a restart. Some of these startup items run with higher privileges, so it can also help the attacker gain more control.
