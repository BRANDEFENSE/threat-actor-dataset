# Drive-by Compromise

Drive-by Compromise is a way for attackers to gain access to a computer when a person visits a website during normal browsing. The site, or something it loads, delivers malicious code to the browser. MITRE ATT&CK lists it as an Initial Access technique.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1189 |
| Tactic | Initial Access |
