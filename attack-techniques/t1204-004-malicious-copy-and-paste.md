# ClickFix: Malicious Copy and Paste (T1204.004)

Malicious Copy and Paste lets an attacker run code without an exploit and without a browser download. The user pastes the command into a terminal or the Windows Run box. MITRE names ClickFix, where a fake error or CAPTCHA tells the user to do exactly that, as one such strategy.
