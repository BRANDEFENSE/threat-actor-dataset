# Dead Drop Resolver: Hiding C2 Addresses on Public Web Services (T1102.001)

A dead drop resolver is a page on a legitimate web service that holds the address of the attacker's real command and control server. Malware reads the page, learns where to connect and can be pointed elsewhere by changing the page. MITRE tracks this as T1102.001.
