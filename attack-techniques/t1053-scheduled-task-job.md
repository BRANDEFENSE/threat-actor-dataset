# Scheduled Task/Job

Scheduled Task/Job is a technique where an attacker uses the task scheduling feature built into an operating system. The feature runs a program or script at a set time or on a repeat. Attackers use it to start malicious code, to keep their access after a restart, or to run code with higher privileges.
