# Hide Artifacts

Hide Artifacts is a technique where attackers hide the traces of their activity, such as files, folders, user accounts or running tasks. The aim is to avoid being noticed by users and security tools. Attackers abuse operating system features that already hide items, so what is hidden is harder to find during a routine check. MITRE ATT&CK tracks it as T1564.

| Tactic | Stealth |
