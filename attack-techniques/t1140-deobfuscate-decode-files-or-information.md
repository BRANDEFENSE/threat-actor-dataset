# Deobfuscate/Decode Files or Information

Deobfuscate/Decode Files or Information is a technique where attackers unpack, decode or decrypt content they had hidden earlier, so it can be used on the target system. The malware itself or built-in system utilities can do the work. MITRE tracks it as T1140 under the Stealth tactic.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1140 |
| Tactic | Stealth |
