# Modify Registry

Modify Registry is a technique where an attacker changes settings in the Windows Registry. The Registry holds configuration for the system and its software. Changes can help an attacker stay on a machine, hide data or weaken security settings. MITRE ATT&CK tracks it as T1112 under Defense Impairment and Persistence.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1112 |
| Tactic | Defense Impairment, Persistence |
