# Valid Accounts

Valid Accounts means an attacker logs in with real credentials that were stolen or bought. Because the login is genuine, the activity can look like a normal user. MITRE says the access can be used to get in, stay in the network, gain higher privileges or avoid detection, so defenders watch how an account behaves.
