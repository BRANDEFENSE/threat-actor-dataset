# Remote Services

Remote Services is when an attacker uses a valid account to log in to a service built for remote access, such as SSH, RDP or VNC. Once in, the attacker can act as that user. It is a common way to move from one system to another inside a network.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1021 |
| Tactic | Lateral Movement |
