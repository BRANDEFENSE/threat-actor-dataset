# Archive Collected Data

Archive collected data is when an attacker packs stolen files into compressed or encrypted bundles before sending them out. This makes the data smaller and harder for a defender to read or notice. The attacker can use a utility already on the system, a third party library or a custom method. MITRE ATT&CK tracks it as T1560 under Collection.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1560 |
| Tactic | Collection |
