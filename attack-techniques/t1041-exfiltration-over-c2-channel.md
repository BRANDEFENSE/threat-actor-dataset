# Exfiltration Over C2 Channel

Exfiltration over a C2 channel is when an attacker sends stolen data out through the same channel they already use to control the infected system. The data is hidden inside what looks like normal control traffic, so no second route out of the network is needed. MITRE ATT&CK tracks it as T1041 under Exfiltration.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1041 |
| Tactic | Exfiltration |
