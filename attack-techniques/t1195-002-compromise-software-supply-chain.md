# Compromise Software Supply Chain

Compromise Software Supply Chain is a way for attackers to reach many computers through software they already trust. They change an application before it gets to the user, for example in its source code, its update system or its download. MITRE ATT&CK lists it as an Initial Access technique.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1195.002 |
| Tactic | Initial Access |
