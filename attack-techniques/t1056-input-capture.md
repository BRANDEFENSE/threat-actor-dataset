# Input Capture

Input capture is when an attacker records what a user types or enters, to steal passwords or other information. It can happen silently in the background or by tricking the user into typing into a fake prompt or page. MITRE lists four forms: keylogging, GUI input capture, web portal capture and credential API hooking.
