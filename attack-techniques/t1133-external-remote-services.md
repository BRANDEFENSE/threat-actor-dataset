# External Remote Services

External Remote Services is a technique where an attacker uses a remote access service that faces the internet, such as a VPN or Citrix, to enter a network or to keep access to it. These services exist so staff can reach internal systems from outside. An attacker who gets valid logins can use them in the same way.
