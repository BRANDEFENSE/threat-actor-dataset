# Phishing (T1566): ATT&CK Technique

Phishing is when an attacker sends a message that tricks someone into opening a malicious file, following a link or giving away a password. It is a common first step into a network. Defenders check attachments and links before delivery, use multi-factor authentication and make it easy for staff to report suspicious messages.
