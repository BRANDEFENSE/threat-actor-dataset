# Registry Run Keys / Startup Folder

Windows can start programs on its own when a user logs in. Attackers add their own program to the places that control this, the Registry run keys or the Startup folder. The program then starts again after every restart or logon.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1547.001 |
| Tactic | Persistence, Privilege Escalation |
