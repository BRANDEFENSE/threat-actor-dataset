# Virtualization/Sandbox Evasion

Virtualization/Sandbox Evasion is when malware checks whether it is running inside a virtual machine or an analysis sandbox, and changes what it does if it is. The aim is to avoid being studied. MITRE lists it under both Stealth and Discovery.
