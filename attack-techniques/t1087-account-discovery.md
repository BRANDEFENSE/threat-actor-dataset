# Account Discovery

Account Discovery is when an attacker builds a list of valid accounts, usernames or email addresses on a system or inside a compromised environment. Knowing which accounts exist helps them plan what to do next. MITRE ATT&CK lists it as a Discovery technique.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1087 |
| Tactic | Discovery |
