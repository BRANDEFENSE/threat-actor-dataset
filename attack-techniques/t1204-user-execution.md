# User Execution

User Execution is when an attacker gets a person to run malicious code for them. The person might open a file, click a link or turn on a remote access tool without knowing the risk. It is an Execution technique in MITRE ATT&CK.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1204 |
| Tactic | Execution |
