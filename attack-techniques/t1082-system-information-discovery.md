# System Information Discovery

System Information Discovery is when an attacker collects details about a device, such as its operating system version, patch level and hardware. The attacker uses this to decide what to do next on that device. It is a Discovery technique in MITRE ATT&CK.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1082 |
| Tactic | Discovery |
