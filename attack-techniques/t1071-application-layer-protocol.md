# Application Layer Protocol

Application Layer Protocol is a technique where attackers talk to a system they control using ordinary network protocols, such as those used for web browsing, file transfer, email or DNS. Because the traffic looks like normal traffic, it is harder to spot and block. MITRE tracks it as T1071 under the Command and Control tactic.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1071 |
| Tactic | Command and Control |
