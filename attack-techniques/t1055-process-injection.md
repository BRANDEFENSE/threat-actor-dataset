# Process Injection

Process injection is when an attacker runs their own code inside another program that is already running. The code then borrows the identity of that program. This can help it avoid security tools and, in some cases, gain more access.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1055 |
| Tactic | Stealth, Privilege Escalation |
