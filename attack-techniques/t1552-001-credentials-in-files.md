# Credentials in Files: Stealing Secrets from Config Files (T1552.001)

Credentials in Files means an attacker reads passwords, keys and tokens that sit in ordinary files on a disk or a file share. Config files, .env files and cloud credential files are common targets. The stolen secret is then used to sign in somewhere else. MITRE tracks it as T1552.001.
