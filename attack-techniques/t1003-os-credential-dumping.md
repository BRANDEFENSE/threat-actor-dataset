# OS Credential Dumping

OS credential dumping is when an attacker pulls account login material out of a computer. This is usually a password hash, sometimes a clear text password. The attacker can then use it to move to other systems and reach restricted information.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1003 |
| Tactic | Credential Access |
