# Ingress Tool Transfer

Ingress Tool Transfer is a technique where attackers bring tools or other files from outside into a network they have already broken into. The files are used for later steps of the attack. They can arrive through the attacker's control channel, FTP or other protocols, often using utilities the operating system already includes. MITRE ATT&CK tracks it as T1105.
