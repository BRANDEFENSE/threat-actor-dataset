# Encrypted Channel

Encrypted Channel is a technique where attackers encrypt the traffic they use to control a compromised system. The encryption hides what is being sent, so security tools that read network traffic see only scrambled data. MITRE ATT&CK tracks it as T1573 under Command and Control, and lists Emotet, gh0st RAT and NETWIRE as using it.

| Field | Value |
|---|---|
| MITRE ATT&CK ID | T1573 |
