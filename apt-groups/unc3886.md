# UNC3886

Singapore's cyber agency (CSA) calls UNC3886 a state-sponsored group without naming a state, and MITRE ATT&CK describes it as China-nexus, in entries dated 2025 and 2026. The group is reported to break into firewalls, routers and virtualization hosts for espionage, and CSA says it targeted all four major Singapore telecom operators.

| Field | Value |
|---|---|
| Status | active |
| Motivation | espionage |
| Attributed by | MITRE ATT&CK and the Singapore government |
| MITRE ATT&CK ID | G1048 |
| Targets | Telecommunications, Critical infrastructure, Defense, Technology, Network and virtualization equipment |
| Target regions | Singapore, United States, Asia-Pacific-Japan |
